# Claude Code 接入

此模块调用用户本机安装的官方 Claude Code，不包含 Claude 模型服务，不依赖 CC Switch 应用。

## 使用

1. 从 [Claude Code 官网](https://code.claude.com/docs/en/setup)安装 CLI；在官方终端完成登录或配置自己的服务商。
2. 在 Agent Hub 的“添加 Agent”中选择 **Claude Code**。未安装时可打开官网；“打开登录界面”执行 `claude auth login`；“检查登录状态”只运行 `claude auth status`，不会打开 CLI 主界面，也不会调用模型。
3. 读取模型列表，选择模型并添加 Agent。列表包含官方 `sonnet` / `opus` / `haiku` 别名及本机配置中的模型，**不是账号可调用模型的完整目录**。订阅、API 或代理服务商的实际权限以执行结果为准。档位暂沿用 CLI 默认设置，不虚构可用档位。
4. 确认完全访问授权后可参与项目；需要真实接入测试时，使用 Agent 卡片上的测试按钮，此操作会消耗模型额度。

旧版 CLI 无法返回结构化登录状态时显示“未知”，不会将安装成功或公开模型别名误认为已登录。请更新官方 CLI。执行协议需要支持 print / stream-json、会话 ID、dontAsk 权限模式、工具白名单和逐次 MCP 配置的版本；不支持的参数会作为错误显示，不自动改用交互模式。

## 账号和配置

- 自动检测 PATH、`~/.local/bin`、旧本地目录、npm 全局安装位置；macOS 使用应用已有的 Finder PATH 扩展。也可在连接配置中指定启动文件。
- 尊重 `CLAUDE_CONFIG_DIR`；优先读取 `settings.json`，不存在时兼容旧 `claude.json`。此路径选择逻辑移植自 CC Switch（MIT），见 [第三方声明](../THIRD_PARTY_NOTICES.md)。
- 沿用官方 CLI 的登录、配置、环境变量和服务商。不读取 OAuth 凭据存储、不复制 CC Switch 数据库、不创建自己的订阅登录实现、不改写全局 Claude 配置。
- `ANTHROPIC_BASE_URL`、`ANTHROPIC_AUTH_TOKEN`、`ANTHROPIC_API_KEY` 等由 Claude Code 处理。CC Switch 已写入的兼容配置也会由 CLI 自己读取；若它指向本地代理，那个代理仍必须实际运行。
- 不声称能读取订阅剩余额度；此模块未提供已验证的余额接口。

## 执行和权限

每个项目和 Agent 分别保存官方会话 UUID。续接使用原目录和 `--resume`，工作目录变化时增加新目录，不丢弃旧会话或重放任务。

实施任务仅在用户授权完全访问后运行。普通讨论关闭内置文件、命令工具；只读检查仅保留读取类内置工具。每轮仅挂载本轮获准的 Hub MCP 工具，包括经理有权使用的长期记忆。独立的内置子 Agent、用户全局 MCP 与自定义命令不加入本轮；每轮禁用自定义 hooks，避免在 Hub 任务外额外执行用户挂钩。此接入没有声明工作区沙箱。

本轮 MCP 配置只包含 Hub 身份，不包含提供商凭据；文件在运行结束时删除，POSIX 下仅所属用户可读写。Windows 使用进程 Job Object，macOS 使用独立进程组，停止或超时会结束本轮拥有的进程。

必须收到匹配会话的初始化、所需工具及明确成功结果，且进程正常退出，才认定完成。缺失结果、会话不符、MCP 未连接或协议异常保留记录并报告失败或状态不明，不自动重试付费请求。原生模型别名由官方 CLI 解析，实际模型记录在执行事件中。

## 当前验证范围

已通过模拟官方 CLI 的真实子进程测试，覆盖登录检查、配置兼容与保护、正常回复、MCP stdio 握手和工具列表、会话续接、跨项目隔离、原目录续接、异常退出、脱敏、超时清理与权限参数。现有适配器与界面回归另行运行。

**尚未使用真实 Claude Code 账号进行推理、工具调用和 macOS 实机验收。** 模拟测试不代表所有 CLI 版本、订阅及第三方提供商已兼容；发布前应在已安装并登录的环境中执行真实接入测试。
