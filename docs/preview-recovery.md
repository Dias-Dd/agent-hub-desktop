# 休眠后的演示预览恢复

根因：预览 capability 链接一小时过期，后端重启也会使内存 ticket 失效。旧前端一直复用这些地址，切换页面后显示无法打开。

修复：切页先探测链接；404 等失败后重新通过用户鉴权 design_content 获取同版本预览链接。窗口重新获得焦点、页面重新可见及每分钟检查都会恢复；链接超过45分钟主动更新。预览探测10秒超时，网络恢复后可自动再试。请求结果绑定原项目/版本对象，过期异步结果不会覆盖新项目或新页面。

恢复仅替换预览地址，不重建页面导航、草稿、框选、缩放、滚动位置，不生成新演示，不触发模型调用。不延长旧 ticket 有效期，不放宽预览沙箱或 CSP。

验证：三种窗口下模拟 ticket 404 与休眠两小时，均重新取链接，保留多页/整体意见及框选；刷新恢复测试、经理布局、阅读状态、九宫格回归通过。
