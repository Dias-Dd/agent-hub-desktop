# 聊天时间与阅读跟随

经理聊天与群聊均按时间从旧到新显示，最新消息在底部，每条消息使用time元素显示本地时间。新讨论历史写入真实created时间；已有经理回复可根据对应执行记录finished/created恢复时间，无法核实的旧记录显示“时间未记录”，不会用轮询当前时间伪造。未知时间的历史保持稳定顺序。

经理阅读区与群聊分别按项目保存滚动位置：距离底部24px以内跟随刷新；向上阅读时保留位置；切换聊天时恢复各自位置；新项目首次打开跟随底部。历史分页按钮在上方，默认显示最近30条；阅读历史时新消息不会导致原先可见历史被30条窗口挤掉。轮询继续更新，只有滚动跟随有条件限制。

真实Edge新增回归覆盖两类聊天的时间戳、升序、底部自动跟随、上翻后追加保留位置与已有执行记录时间恢复。经理三尺寸布局、七列表阅读、九宫格三尺寸与草稿回归通过，相关Python讨论逻辑测试通过。没有停止正在运行的Agent。运行版静态文件已更新；完整EXE/源码包同步用于后续启动。
