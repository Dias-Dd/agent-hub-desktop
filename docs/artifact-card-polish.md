# 网页展示卡片样式补齐

网页与图片展示消息此前仍使用旧的顶部“发送者→用户·时间”布局。本次改为底部灰色小字信息栏，悬停、键盘聚焦时显示来源、类型、发布时间、放大和复制链接；触屏常显。既有聊天灰色信息对齐不变。

卡片内部24px留白（窄屏20px），外侧18至32px，卡片间28px（窄屏24px）；标题与预览、预览与底部操作分开留白。放大查看、隔离iframe、重复打开及刷新时保留iframe节点仍有效。网页卡片按真实发布时间升序；这不代表强制把尚在生成的回复纳入历史时间排序，流式回复仍保持末尾。

新增浏览器用例覆盖三个窗口大小的灰色底栏、左右/上下留白、链接复制、发布时间排序、预览放大、刷新保留iframe与阅读位置。旧展示用例的静态页面响应已与实际服务的frame-ancestors self策略对齐，避免测试预览被夹具自己的CSP阻止。另回归经理布局、阅读、Agent面板、平铺聊天与执行动效。不触发模型调用或重启服务。

7项相关浏览器回归通过，均含相应窗口/交互检查；截图已人工查看。桌面构建及独立启动检查通过：ok=true、assets=10、simulation=false、native_available=true，退出码0。当前运行实例前端已备份更新并核对HTTP响应，刷新即可生效。
