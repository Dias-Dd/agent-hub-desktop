# Agent 推理档位与导航布局

## 当前官方能力

本机DeepSeek Harness 0.2.1-rc.2通过ACP session/new返回reasoning_effort，支持off/low/high/max，默认high。界面显示关闭/低/高/最高；这是推理强度，模型始终为deepseek-flash，不会切换到Pro。本次已实际对四个值调用官方session/set_config_option并核实返回值，未发起推理。

每个身份独立持久保存档位；每轮开始先读取该会话实际配置，必要时设置，并核对提供商确认。切换只影响下一轮，不中断当前执行；会话ID和历史保持不变。执行事件记录真实使用档位。未提供或未确认档位则明确失败，禁止静默使用另一档。

## 告知经理（按用户最终要求）

仅在purpose=discussion的system persona policy中直接列出九个Agent当前档位。常规经理派工/巡检不加入整份列表。

变化时创建平台→经理的queue消息，内容只有本次差量、下一轮生效说明。活跃项目同时创建调度事件；未活跃项目只持久保存队列，不调用模型、不恢复项目。下次该项目经理被唤醒时把未送达消息一并带入；提供商确认完整结束才标记送达，失败/取消时保留。项目和收件人隔离，重复选择相同值不重复通知，只有用户可以修改档位。

## 界面

最左侧52px图标栏包含沟通、九宫格、额度与窗口速览、底部配置中心；文字说明通过title/aria-label提供。额度图标打开弹出面板。旁边项目工作区采用逐行列表和当前项目高亮，取代下拉框，并保留最近项目恢复。九宫格每张卡片包含档位选择，仍在当前屏幕内显示，长文本折叠。

## 验证

官方ACP元数据及四档设置真实验证；22项Harness测试（含默认/恢复/官方档位设置时序、讨论专用system列表、通知失败保留/成功确认），11项档位与身份测试通过。真实Edge检查窄图标栏、项目行切换、额度弹层和九个选择器持久化；九宫格四尺寸、经理三尺寸布局、阅读位置、聊天时间跟随、最近项目与草稿、九身份回归通过。部署前两份数据库备份；确认没有在途任务后更新运行服务，未重放旧任务。
