# 用户气泡、执行动效与准确阶段

用户消息右侧显示为气泡，经理正文保持无卡片样式并默认展开。执行操作显示在流式回复正文下方，包含实际运行身份和公开工具状态；可从 Harness/Codex 工具事件提取状态，缺少细节时只标明执行中，不虚构动作。经理空闲但成员仍运行时操作行继续显示，全部完成后移除。运行/确认中断使用轻量三点动效，排队及等待额度不伪装为持续执行，系统减少动态效果偏好有效。

顶部取消重复的实时操作提示与执行阶段的讨论版本号。依据关联工作流、设计及讨论状态显示需求讨论、计划待确认、演示待确认、正式制作、暂停、完成等阶段。修复讨论保留 executing 导致实际完成/暂停项目仍显示执行中的问题，也防止旧演示完成状态被误当成正式制作完成。
