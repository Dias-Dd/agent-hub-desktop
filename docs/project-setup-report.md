# 新建项目流程更新（2026-10-20）

左侧只保留＋图标。点击后在窗口中填写名称、工作目录、制作流程及参与 Agent。工作目录可手动填写，也可通过 Windows 原生文件夹选择器浏览；留空自动创建独立目录。创建后进入经理聊天，用户发送需求才开始讨论，批准计划后才派工。弹窗右上角关闭按钮统一为 ×，保留悬停说明和无障碍名称。

新 API：用户专用 project_browse_directory；project_create 支持 cwd/options，配置持久化于 SQLite project_options。没有修改已有项目会话、凭据或执行权限。
