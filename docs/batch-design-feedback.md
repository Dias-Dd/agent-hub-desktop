# 多页演示反馈与连续缩放

每页意见与框选独立保存，切页不会提交。整体意见独立输入。点击“一次提交全部修改意见”将全部已填写页面和整体意见作为一次请求提交，经理统一制作一个新版本。输入为空的页面不发送；失败保留草稿，成功清除已提交草稿。草稿按项目和设计版本隔离，刷新可恢复。

design_feedback 支持 entries（page_id/body/scope/region）和 overall，保留旧单页调用兼容。全部条目校验完成后只启动一个设计修订。

滚轮按距离连续缩放，范围5%–200%，指针位置作为缩放锚点；按钮按比例调整，适应窗口连续计算。通过同源样式表 CSSOM 更新缩放，不放宽 CSP。中键拖动及清除框选保持可用。

验证：设计流程12项、演示浏览器两项（含三种窗口、批量提交、整体草稿刷新、连续缩放），经理布局、阅读状态与九宫格回归通过。全程使用模拟接口，不调用付费模型。
