# 可恢复状态处理修复（2026-10-19）

1. 讨论24小时过期：用户继续讨论时续期同一个讨论，原会话和历史不变；不自动批准或恢复项目执行。旧执行审批仍按有效期检查。
2. 执行已经结束、讨论pending尚未同步：发送新消息前同步已结束结果，再正常处理新消息；真实在途执行不重复提交。
3. 经理普通文字或结构化格式不合规：保留原文作为可继续讨论的答复，状态draft，不抛弃上下文；没有有效结构化计划不能启动执行。附加JSON元数据通过共同解析器处理。
4. 已执行计划继续收到讨论消息：按当前讨论的经理和项目发送queue消息，不要求用户手动新建讨论；消息仍受停止锁与项目路由约束。
5. 完全访问权限下确认新的项目目录：正常绑定用户指定的存在目录，保留授权身份和会话，不再受旧workspace根目录限制；workspace权限仍限定原范围。

新增7项回归测试分别验证以上路径及普通答复不能派工、workspace边界不放开。逻辑恢复测试13项（含6项既有身份测试）、Harness测试18项、前轮简化测试5项均通过。没有使用实际付费模型调用来测试，没有重放旧任务。

上一轮同项目换目录的Harness兼容修复继续保留：使用原会话启动目录恢复原ID，把当前项目目录明确交给模型，不篡改官方持久会话文件。
