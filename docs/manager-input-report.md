# Argon 新增输入精简

日常目标400字以内，不按长度拒发、不截断原文。固定规则231字符，只在必要时加入；同一持续会话不重复。自然分批时预留规则空间，长原文允许单独完整送达。多余消息保持pending，不会认领后隐去。

用户单条短消息保持原文；多条消息按发送者分隔。平台生成的主动汇报去除run ID、重复JSON字段、长证据数组，直接呈现发送者、结果、必要风险；完整消息与证据通过project_status(view="events")读取。原始直接消息不改写。

旧任务正文和完整执行记录不混入自动通知。平台恢复说明缩短为必要动作；详细检查交给成员，Argon只判断结论。只有成功结束回合才确认本批事件，失败保留重投。第一轮创建主动汇报后即查消息ID，修复首次事件缺失原消息关联的问题。

验证包括短批次实际新增内容不超过400字符、长原文不被截断拒发、未选消息不被认领、多批次完整送达、执行中新消息留待下轮、同会话不重复规则及完整证据可查询。此目标不等于历史上下文或模型主动读取的工具结果总长度限制。

结果：165项完整回归通过；当前回合自然结束后加载，恢复原并行度8。最新真实manager.input记录399字符，包含一次性精简规则和Sol-2结果，不含旧任务正文及JSON证据包装。未为精简额外调用模型。
