# 连续聊天界面

经理聊天和 Agent 动态改用无卡片外框的连续消息，横线分隔，正文完整展开，原始 JSON 回执尽可能显示为自然语言正文。用户正文靠右；经理及成员正文靠左。移除聊天底部重复列出全部工作流需求与汇报的卡片，原数据和整体进度保留。

发送者、状态、时间与复制按钮放在每条消息底部，灰色小字号；鼠标悬停、键盘焦点时出现，触屏常显。复制完整正文，复制失败可手选。技术性的实际输入从底部操作打开独立阅读窗，不占据日常聊天；流式原始草稿仍可复制。正文与公开摘要没有默认折叠，也不使用消息内的限高滚动区。

流式消息移至 managerReadingArea 的最后，位于历史、审批与产物之后。仍在底部时跟随新内容，向上阅读时保持位置，不抢走草稿和选中文字。保留审批门禁和输入框可见性，展示草稿不代表任务已完成。

验证：新增浏览器测试覆盖三个窗口大小的完整长正文、分隔线、底部元信息隐藏/聚焦显示、复制、流式位置、节点与滚动保留。回归经理布局、阅读状态、九身份面板、聊天时间顺序、空闲刷新性能、发送按钮与 live 测试；视觉截图已检查。所有页面测试使用模拟状态，无真实模型推理。

相关浏览器与流式回归共20项通过；桌面独立启动 ok=true、assets=10、simulation=false、native_available=true，退出码0。运行实例五个前端文件已备份并更新，HTTP返回的脚本/样式与新增HTML挂载点验证通过；没有重启服务。
