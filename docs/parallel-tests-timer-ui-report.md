# 并发接入测试与右侧状态、计时器

## 行为
- 全部测试最多8个同时进行，余下队列自动补位；多个单独测试共享同一上限。一个Agent已有待执行/进行中的接入测试时不重复提交、不覆盖其结果。
- 测试并发独立于项目的实施并发设置：测试池与执行器均最多8个，项目工作仍受原max_parallel约束。模型预算、启用状态、权限、停止锁仍沿用原授权；真实调用需要用户确认。提供商限流不自动重试，也不猜测限流一定由并发导致。
- Agent极简状态区域取消自身高度限制和滚动，随数量增高，整体右侧栏仍可滚动访问下方内容。名称保持一行，溢出时自动往返滚动；悬停/聚焦暂停，系统减少动态效果时停止动画。轮询不重建相同状态，避免跑马灯持续重启。
- 计时器用圆角卡片显示HH:MM:SS倒计时、附言、发送方→接收方与实际到期时间。每秒只更新数字，不新增请求、不重建卡片。休眠恢复后按绝对due校正。
- 右侧叉号取消待执行提醒并隐藏卡片；已结束记录只从当前浏览器视图移除。服务端历史和审计保留，按项目记录隐藏状态。

## 验证
事件同步测试证明两个独立单测重叠执行、重复提交不会调用、9个身份分成最多8并发；在项目并发设为1时两个接入测试仍能真实经过运行时并发调度（提供商边界使用替身，无真实调用）。Edge验证单行溢出动画、无区域滚动、小时分钟秒、收发方/附言、叉号取消与卡片移除。1440x1000截图检查布局；正常/短/窄窗口回归和阅读状态回归通过。
