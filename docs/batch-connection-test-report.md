# 全部 Agent 真实推理测试

- Agent 面板入口为“全部测试”，弹窗明确说明会消耗订阅额度或 API 余额，用户点击“开始真实测试”后才提交。
- 使用各身份现有的真实运行时（Codex、Antigravity、DeepSeek Harness、OpenCode、Ori、WorkBuddy、Claude Code 和兼容 API），不另写绕过登录的调用路径。
- 最多8个测试并发，超出时滚动分批；支持同时启动多个单独测试，同一Agent去重；每个 Agent 最多提交一个独立测试轮次。继承连接启用状态、预算、全局停止锁、并发控制与权限。
- 正在工作/排队、未启用、被锁定或无执行器时记录跳过原因。不会自动启用接入、调整预算、切换模型或打断项目任务。
- 使用新的 connection-test 会话和空目录，不复用项目上下文。请求只回复“连接成功”，不提供 Hub 派工工具。对话模式使用现有只读适配器。
- API 测试输出上限32 token；测试最长为当前授权时限与90秒中的较小值。额度等待/失败/不确定执行不重试；超时请求停止，明确提醒可能已计费。
- 结果持久化并在各 Agent 卡片显示；详情含时间、模型、档位、回复和原因。配置变更后旧测试明确标记“旧配置”。不向右下角逐条弹通知，不投递用户/经理聊天，不唤醒经理。
- 服务重启把未确认测试标为中断，不自动续跑。全局停止仍然生效。

## 验证
后端确认门禁、忙碌与未启用跳过、错误去敏、重启不重放通过；模拟 ACP 经真实运行时验证仅一次 prompt、独立会话/目录、不发送用户消息。真实 Edge 验证确认弹窗、卡片结果与详情展示。全部测试未向真实模型发送请求。
