# DeepSeek 配置、额度通知与接管

## 开始使用

刷新主页，点击顶部“配置 DeepSeek API / 备用经理”。

1. 填写官方 API Key 并保存。密钥存入 data/deepseek-key.dpapi，由 Windows 当前用户 DPAPI 加密；服务重启后可读取，不出现在状态响应、审计或下载包中。也兼容 DEEPSEEK_API_KEY 环境变量。不要把 data 目录交给他人。
2. 点击“验证连接（不推理）”。仅请求官方 GET /models，必须返回 deepseek-flash；无法验证时不启用。不替换为其它模型。
3. 选择项目目录、文件读写或完全访问权限、总预算（美元美分）、任务回合数、每回合付费请求数、时限和输出上限。按官方价格核实输入/输出单价；输入按较高的非缓存价格估计。勾选执行授权；需要备用经理时勾选接管授权。保存不会发起推理。
4. 新项目将 DeepSeek 勾选为参与者，仍需确认“按计划执行”。已有未结束项目可点击“确认将 DeepSeek 加入当前项目并授权接管”；该按钮明确追加参与者与接管授权，不解除项目暂停。项目目录可为 DeepSeek 已授权目录的子目录。DeepSeek 保留独立回合数、费用预算和时限，不必覆盖整个项目的总回合；项目配置不会扩大这些授权。

本向导不再要求手动设置 HUB_ALLOW_REAL。旧版单次文本调试入口已折叠，仍使用独立的环境变量与逐次审批流程。

## 费用与工具执行

固定官方 https://api.deepseek.com，通过 Chat Completions 的 function tools 循环执行。每个项目身份持续保留自己的会话，后续追加新任务与工具结果，重启不重放不确定执行。

工具包含项目状态/收件箱、私聊、短汇报；正式实施任务可读写项目内文件。只有选择完全访问后才允许本机命令，命令在 Windows 当前用户权限下运行，不是沙箱，也不会自动获得管理员权限。独立检查和同事质询不开放写入与命令工具。

每次付费请求发送前，根据序列化输入字节、输出上限及用户确认的单价保守预留整数美分。总费用预留不超过该授权预算；不自动释放旧预留，不自动充值。输入单价若低于真实官方价格，该估算不能保证真实账单上限；供应商价格或账户额外使用也不由 Hub 控制。每回合另有请求数/时间上限。HTTP错误、限流、超时不自动重试；可能已收费或产生文件变化的执行标为不确定。停止阻止下一次请求并终止本地命令树，已发送的 API 请求无法保证服务端取消。

## 额度提醒

常驻非模型监视器每180秒读取官方 CLI 额度；执行前已有新快照也会被检查，不进行推理探测。剩余严格低于10%发一次提醒，达到0%再发一次。状态持久化去重；恢复到至少10%后重新计数。多窗口分别提醒，恢复时间仍是预计值。未知/过期（超过10分钟）快照不当作耗尽。

提醒发给用户，并作为结构化项目事件交给当前经理；暂停项目只保存事件。Argon 自身低额度/耗尽也向 DeepSeek、Astra 留下通知；这类通知本身不单独授权额外付费模型调用。

## 经理接管

只有项目已批准 DeepSeek、匹配的执行与费用授权、并明确授权接管时，Argon 被官方快照确认耗尽才允许 DeepSeek 接任。先等待正在运行的 Argon/DeepSeek 自然结束；原 Argon 排队或等待额度的经理回合取消并保留记录，待处理事件交给新经理。不会中断仍运行的原经理来强行启动第二个经理。

平台只允许当前经理的 plan/review 回合调用项目派工、取消、角色调整和完成验收工具。普通 DeepSeek 执行任务不会因身份相同取得经理权限。接任时读取批准范围和必要状态，不复制 Argon 私有长对话，不重派在途任务。完成仍受最新独立检查、风险、在途任务与新消息检查约束。

Argon 恢复后不自动抢回管理权，避免双经理。暂停、停止锁、预算不足、授权到期或不匹配时不接管。若 DeepSeek 也不可用，不会自行扩大预算或切换其它付费模型。初始计划讨论仍由 Argon 负责，本版接管面向已授权执行项目。

## 后续更新：恢复通知与交回经理

Argon 正常可用时即可给已获授权的 DeepSeek 派普通实施任务，无需等待接管。DeepSeek 做执行者与做经理使用同一预算，但只有 plan/review 经理回合拥有管理权限。

额度按每次实际跨越阈值通知：低于10%、耗尽、恢复；例如0→5%会通知部分恢复，再降到0时再次通知耗尽，恢复到至少10%后再次跌破10%时再次通知低额度。通知去重状态持久化，兼容旧版高水位记录，重启不重复播报稳定状态。

Argon 所有已知且新鲜的适用窗口至少20%时，视为额度充足：通常通知 Argon；不足20%、未知，或当前经理为 DeepSeek 时，同时通知 Argon 与 DeepSeek。仅当前经理通过合并项目事件唤醒，另一方保留收件箱通知，避免同时唤醒两个经理耗费额度。用户也会收到通知。当前经理是 DeepSeek 时，成员的相关额度预警和恢复信息不会遗漏 DeepSeek。

Argon 恢复充足时，通知和代理经理 Prompt 鼓励 DeepSeek 调用 project_return_manager 申请交回管理权。平台不强制抢回：等待当前提供商回合结束并完成处理，重新核实额度、授权、停止锁和调用预算，再由 Argon 延续原会话。交接期间禁止新派工；如果额度再次下降或变为未知，取消交回申请，DeepSeek 继续管理，不会卡住。项目暂停/停止时不交接。

本轮新增模拟验证：Argon 直接派工 DeepSeek 并执行、按当前经理路由通知、未知/低额度同时通知、恢复时建议交回、低额度拒绝交回、忙碌回合等待、额度再次下降取消交回、交回幂等。无真实模型推理调用。

本次完整回归136项测试通过，其中32项覆盖 DeepSeek 与额度协作。交回工具成功后直接结束当前回合，不为格式确认额外发送一次付费 API 请求。
