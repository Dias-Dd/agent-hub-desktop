# 经理图标输入与侧栏（2026-10-19）

- 空闲：发送箭头；没有文字则灰色禁用。
- 忙碌且输入文字：排队图标，点击后保存消息，继续输入可连续排队。
- 忙碌、输入为空且有自己待领取的消息：按钮变为“中断并插入”图标，点击将这些消息优先处理，并请求取消当前经理轮次。先等待执行器结束当前轮次，再处理输入，不开启两个并发的经理轮次。
- 所有模式都有原生悬停提示与可访问名称；请求期间禁用重复提交。仅操作当前项目经理，其他 Agent 与项目停止锁不变。
- 讨论中也允许排队；讨论输入按原会话逐条处理并持久化，重启不丢。队列里的“按计划执行”不会自动批准未经审阅的新版本。
- `manager_message` / `manager_interrupt` 为仅用户可调用的 HTTP Action，携带当前讨论ID与项目头；运行ID和讨论ID不混用。被用户中断的经理轮次不计为自动恢复失败，不重放旧派工。
- 总体进度卡最多48dvh，超出在卡片内滚动。下方3×3极简状态仅显示身份和busy/idle/offline，无任务正文、模型、角色或额度。
