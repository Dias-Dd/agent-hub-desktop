# 动态调度与异常恢复验证（2026-10-18）

## 行为
- Supervisor 每 0.25 秒检查本地状态，不调用模型。
- 完成或检查结果触发 Argon 动态调度，相邻事件至少合并 15 秒；经理忙时继续收集，不中断其余成员。
- 独立检查者可以在其余任务仍运行时核查已完成结果；有新证据才调用，运行中检查至少相隔 300 秒。整批结束仍执行验收检查。
- Argon 可以给空闲参与者补派独立工作；忙碌身份的重复分工不会取消原任务，任务仍受原授权与并行上限限制。
- 检查者建议先交经理协调，避免直接并发修改同一产物。
- Argon 上下文包含已读取的官方额度、快照时间/过期标记及最近项目执行用量。订阅额度、token 和 Hub 回合预算分别计量；未知不推算，额度不等同金额。
- OpenAI 每次真实执行验证官方额度后保存快照；Antigravity 每次启动前刷新官方额度。空闲时不会为读取余额启动推理。
- 不再重复附上整份已批准计划；运行时移除手动心跳、消息确认等重复说明。保留原需求、验收条件和近期短报告。厂商内置提示、工具输出和缓存用量仍会产生额外 token。

## 异常恢复
Antigravity 官方最终响应先持久化，再等待本地进程退出。已验证模型/权限且收到 SUCCESS 时，单纯退出等待超时不丢弃成功结果；没有最终事件依然不能记成功。
经理异常在原授权内最多连续恢复两次，先只读核查现场。工作执行不确定时安排独立现场检查，不重放原任务、不把“已检查”当作“已完成”。用户紧急停止、授权过期或权限变化仍不会自动解除。
