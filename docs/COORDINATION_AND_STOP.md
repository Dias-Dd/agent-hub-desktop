# 主动汇报、受控唤醒与紧急停止

2026-10-18。本次新增功能通过模拟执行器、真实 HTTP/MCP 协议和停止进程接口测试，未新增真实模型调用。之前的 Argon→Sol→Argon 真实联调仍保留，但不代表本次独立检查/消息链功能已经额外消耗订阅额度做过模型联调。

## 推荐设置

工作者完成后主动提交 JSON 短报告：summary、risk、evidence、messages、stop_agents。完整输出仍保存在执行记录。平台将执行者的摘要、风险、验证证据发送给 Argon；批次内合并汇报，不为每个普通回执单独消耗 Argon 调用。

页面默认选择 Flash-3 独立检查，Argon 看简报。检查者可选 Flash-3、Astra 或 Argon。Flash-3/Astra 检查模式最少四次调用：分工、工作、独立检查、Argon 最终汇报；Argon 统一检查模式最少三次。检查者必须在项目参与者里，提供商预算也须够用。检查者报告 high/blocked，或本轮执行失败时，平台拒绝直接验收通过。监督不只依赖模型：平台检查心跳、退出状态、授权、额度、消息链及执行是否确定。

摘要按字符截断、证据限长，减少经理上下文；这是减少重复输入的机制，不承诺具体 token 节省比例。大项目仍应产出可检查文件和测试证据。

## 消息唤醒

项目授权页面默认启用「项目内消息自动唤醒」。消息进入 SQLite，绑定原项目、发送执行和原消息 ID，由对应真实执行器领取；忙碌时排队，同一时间一个真实任务。MCP send 接口发送后即可路由；immediate 仍按既有提供商停止/中断机制处理，不能声称无损抢占。

内置 CLI 本轮结束时可通过结构化结果提交主动消息。当前没有把 Hub MCP 动态注入每个内置 CLI 会话，因此这条路径不保证工作中途实时收发；已连接 Hub MCP 的外部客户端可以途中发送。读取过本机官方 CLI help/schema，未凭空假设 CLI 支持临时 MCP 配置参数，也未修改全局 MCP 配置或复制登录凭据。

仅有效项目内已授权身份之间的消息可启动模型。项目外、过期、停止、没有执行器或不属于项目的消息保留为 held，不能绕过用户权限。DeepSeek 目前仍没有完整任务执行器，消息不能启动它。

防循环规则：唯一消息去重；每条消息绑定原任务；默认最多四层消息链、十二条消息唤醒记录，另受项目总调用次数和提供商预算限制；为最终检查预留次数；普通结果回执不再自动向原发送者回一条回执；发给 Argon 的结果合并到批次检查，禁止礼貌性互相确认。需要沟通时 messages 列表最多四条，每条最多2000字符。到达限制后保留消息和原因，不继续唤醒。

## 用户停止按钮

顶部有「立即停止全部 Agent」，也有九个单独停止按钮。操作先写入持久化启动锁，再取消未启动执行，并终止目标 Agent 的 Hub 自有本地 CLI 进程树。单独停止会停止该 Agent，并停止相关项目后续调度、取消相关项目排队步骤；其他 Agent 已经运行的独立回合可以结束。全部停止针对全部身份。

Supervisor 不会因重启解除锁，普通 MCP enable/心跳不能绕过锁。只有用户可点「解除启动锁」，解除后不重放取消或 uncertain 的工作；重新授权新项目。模型没有解除锁、增加预算或恢复任务的工具。

本地进程树终止无法保证服务端已取消，已发生的费用和文件改动不回滚；Codex/Antigravity 的已提交运行可能标为 uncertain。DeepSeek 已发送 API 请求没有官方可用取消确认，标 uncertain 并保留预算，停止后禁止新请求。

## 模型止损权

建议默认由用户独享停止权，页面「委托 Argon / Astra / DeepSeek」默认不勾选。用户明确委托某项目后，这三个固定管理身份可通过 MCP agent_halt(agent,reason) 停止该项目中的一个参与者。它们不能全局停止、停止项目外身份、恢复执行或扩预算。

内置 Agent 可在结构化 stop_agents 中提出停止；只有授权角色、有效项目且用户启用委托才执行。DeepSeek 没有本地执行器，这项角色权限供已连接且持有该身份凭证的 MCP 客户端使用，不会自动产生 DeepSeek API 消费。

## 验证

新增测试覆盖：原消息直接启动并幂等；执行者主动报告；独立检查再向经理提供短上下文；严重检查结果阻止假通过；消息链阻断；未授权身份不能启动；单独/全局停止与重启持久化；只有用户可解除；模型委托默认关闭且范围受限；只结束目标自有运行；回执不回执；模拟 Agent 同样服从停止锁；HTTP 配置和停止路由；MCP 工具权限。
