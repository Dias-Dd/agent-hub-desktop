# VM状态、标签、正文区域及侧边栏动画

VM状态：独立检查helper进程，20秒无心跳但进程存活时标为等待状态更新，不把它当服务已停止或再次提权；短暂状态文件读取缺口使用上一次快照，仍按真实心跳时间判断连接。启动期间跨VmBridge实例合并同一根目录的启动请求（90秒启动窗口），缩略图轮询永不启动管理员组件。状态徽标与文字区使用一致的启动/部署/更新/断开状态。真正连接断开依旧如实显示，不伪造已连接。

队列：修复消费缩略图后删除请求、helper仍遍历旧文件清单而读到不存在文件的竞态；跳过已删除请求，损坏请求标失败不执行。异常退出保存不含凭据的异常类型、错误号与行号，便于后续定位。电源查询短暂失败保留上次观测并标注，不立即清空运行状态触发无谓重连。

UI：三个标签均用底色+内阴影表示激活，避免透明边框规则吞掉下划线。状态页概览与Git行高分别360/420逻辑像素；概览百分比26px，正文/提交树留出更大空间，分支列表限高56px。卡片仍紧凑对齐并保留间距。侧边栏用320ms cubic-bezier(.22,.75,.25,1)动画，保持稳定grid轨道，收起后inert避免焦点落入隐藏区；窄屏改纵向动画，遵循减少动态效果偏好。

验证：32项最终回归通过，包括三项强制UI、真实原生窗口6弹窗及Snap、25项相关桥接/竞态/启动/缩略图测试和断线恢复；另有项目状态正文高度与3标签/侧边栏实际中间帧浏览器测试通过（1640/1440、1024、600宽度）。没有调用模型或重启用户当前VM桥接；真实的Windows更新/网络或凭据故障仍须按实际状态处理。
